## 📸 Sobre o projeto

O **Black Crown Barbearia** é um site institucional desenvolvido para apresentar os serviços de uma barbearia, fortalecer sua presença digital e facilitar o contato dos clientes.

O visual combina tons escuros, detalhes dourados, imagens temáticas e uma navegação adaptada para dispositivos móveis.

## ✨ Funcionalidades

- 🖥️ **Design responsivo** — adaptado para desktop, tablet e celular.
- 💈 **Serviços e preços** — apresentação dos serviços oferecidos.
- 👑 **Seção sobre a barbearia** — espaço para destacar a marca.
- 🖼️ **Galeria de imagens** — apresentação do ambiente e dos cortes.
- 📅 **Formulário de agendamento** — coleta dos dados do cliente.
- 💬 **Integração com WhatsApp** — prepara a mensagem de agendamento.
- 📱 **Menu mobile** — navegação otimizada para telas menores.
- ✅ **Validação de formulário** — ajuda a verificar os campos preenchidos.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no seu editor de código.
3. Abra `index.html` no navegador.

**Dica:** no Visual Studio Code, você pode usar a extensão **Live Server** para visualizar as alterações enquanto desenvolve.

## 📲 Configure o WhatsApp

Para receber os pedidos de agendamento no número correto:

1. Abra `js/script.js`.
2. Encontre a variável `whatsappNumber`.
3. Troque o valor pelo número da barbearia, com código do país e DDD, usando apenas números.

Exemplo:

```js
const whatsappNumber = "5511999999999";
```

Substitua o número de exemplo pelo número real. Não use `+`, espaços, parênteses ou hífens.

> O formulário abre o WhatsApp com uma mensagem preenchida para o cliente revisar e enviar. O projeto não verifica a disponibilidade real dos horários nem salva reservas em banco de dados.

## 🎨 Antes de publicar

- Atualize os preços ilustrativos e a lista de serviços.
- Informe o endereço e os horários corretos.
- Configure o WhatsApp e os links das redes sociais.
- Substitua as imagens demonstrativas por fotos autorizadas da barbearia.
- Troque o depoimento de demonstração por uma avaliação real, com autorização.
